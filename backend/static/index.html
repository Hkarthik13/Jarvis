🎙️ Enable Microphone on Mobile

Mobile Chrome blocks microphone on local Wi-Fi IP addresses (http://192.168.x.x) by default for security.

Quick 30-sec Fix in Mobile Chrome:
1. Open a new tab and paste:
chrome://flags/#unsafely-treat-insecure-origin-as-secure
2. In the text box, enter:
http://192.168.1.36:8000
3. Change dropdown to Enabled & tap Relaunch.
